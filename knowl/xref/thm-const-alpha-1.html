Theorem 18.1.5.

If \(\alpha\) is constant then
\begin{equation*} \omega_{f} = \alpha \Delta t + \omega_{i}. \end{equation*}
🔗
🔗

Proof.

If the z-component of the angular acceleration is constant then by Definition 18.1.4 we have
\begin{equation*} \alpha = \alpha_{avg,z} = \frac{\omega_{f} - \omega_{i}}{\Delta t}. \end{equation*}
Rearranging, we get
\begin{align*} \omega_{f} - \omega_{i} \amp = \alpha \Delta t \\ \\ \omega_{f} \amp = \alpha \Delta t + \omega_{i} \end{align*}
